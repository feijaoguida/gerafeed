# Task: 062-source-wp-relation

## Objetivo
Vincular feeds RSS a sites WordPress específicos.

## Escopo
- Tela de Fontes RSS (`/dashboard/sources` ou `/settings/rss`).
- Adicionar um *Select* para o usuário associar o feed a um dos sites WordPress cadastrados no Workspace.
- Na hora de criar/editar um `WordPressSite` (Task 061), também mostrar a listagem de feeds atrelados a ele.

## Definition of Done
- [ ] Feed vincula corretamente a um `WordPressSite`.
